FELIZ VIAJE VILLA INSURGENTES - Cómo publicar el sitio en Vercel
=================================================================

Contenido:
  index.html        -> la página del portal
  api/ofertas.js    -> función que trae las promociones de tu catálogo viaje.ly
  package.json      -> le indica a Vercel que use Node.js 18 o superior

Opción A (recomendada): con GitHub
 1. Crea una cuenta en github.com y un repositorio nuevo (por ejemplo "feliz-viaje").
 2. Sube estos archivos respetando la carpeta api/ (botón "Add file" > "Upload files").
 3. En vercel.com entra con tu cuenta de GitHub > "Add New..." > "Project".
 4. Elige el repositorio > "Deploy". No cambies ninguna configuración.
 5. Cada vez que cambies un archivo en GitHub, Vercel publica la nueva versión solo.

Opción B: desde tu computadora (requiere Node.js instalado)
 1. Abre una terminal en esta carpeta.
 2. Ejecuta:  npx vercel        (la primera vez te pide iniciar sesión)
 3. Para publicar en tu dominio final:  npx vercel --prod

Tu dominio:
 - En Vercel > tu proyecto > Settings > Domains, agrega tu dominio y sigue los
   pasos para apuntar los DNS desde donde lo compraste.

Comprobar que funciona:
 - Abre  https://TU-DOMINIO/api/ofertas?region=europa
   Debe mostrar texto que empieza con {"ok":true ... y una lista de "paquetes".
 - Las promociones se guardan 30 minutos en la red de Vercel para cargar rápido.

Nota: no subas el archivo ofertas.php aquí; ese es solo para Hostinger.
